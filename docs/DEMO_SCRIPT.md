Do not break this flow.

1. Admin opens Timetable and clicks Generate. Summary shows lectures placed, 0 conflicts, unscheduled count.
2. Admin opens Workload. All faculty are within limits.
3. Switch to Dr. Sharma. He sees CSE-3A, Room 101, Fri 09:50-10:40, DBMS.
4. Dr. Sharma opens Mark Leave for that Friday. The impact list shows affected lectures. Confirm.
5. The Open Slot appears amber/OPEN in the grid.

7. Kaur picks Operating Systems. The 5 checks show green. Confirm.
8. The timetable now shows Operating Systems - Prof. Kaur. Workload is updated. The Admin dashboard shows 1 academic hour saved.
